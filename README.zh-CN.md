# Mo-Interpreter

[English](README.md)

一个使用 C++17 编写的 Mo 语言解释器。解释器会读取 `.mo` 源文件，将语句解析成语法树后执行，支持整数运算、变量、条件分支、循环、字符与整数输入输出，以及基于虚拟机内存的寻址操作。

## 功能概览

- 变量可直接赋值，无需预先声明；变量值使用有符号 32 位整数保存。
- 支持前缀表达式和带括号的中缀表达式。
- 支持加、减、乘、除、取模、比较，以及按位与和按位或。
- 支持 `if` / `else` 条件分支与 `while` 循环。
- 支持整数输入输出和字符输入输出。
- 支持通过 `@` 访问虚拟机内存。虚拟机有 262,144 个 32 位整数单元，共 1 MiB。

## 快速开始

### 环境要求

- 支持 C++17 的 `g++`。
- GNU Make。
- Windows 用户可在 MinGW-w64 或 MSYS2 环境中使用 `g++` 和 `make`。

建议将项目放在纯英文路径下，以减少 Windows 下的路径编码问题。

### 编译

在项目根目录执行：

```sh
make
```

Windows 下会生成 `Mo.exe`；Linux 和 macOS 下会生成 `Mo`。清理生成文件：

```sh
make clean
```

### 运行

Windows PowerShell：

```powershell
.\Mo.exe
```

Linux 或 macOS：

```sh
./Mo
```

启动后，解释器会扫描与可执行文件同级的 `MoProgram` 目录，并按文件名列出其中的 `.mo` 程序。输入编号运行对应程序；输入 `0` 后可以输入文件名（例如 `factorial` 或 `factorial.mo`）；输入 `-1` 退出。程序运行结束后，Windows 会提示按任意键继续，其他平台会提示按回车继续。

手动输入文件名时不要带空格；含空格的文件名可以从菜单中选择。Linux/macOS 的可执行文件需要在能够找到 `MoProgram` 的位置启动；macOS 上可从项目根目录运行。

## Mo 语言语法

Mo 使用空白字符（空格、换行等）分隔词元。建议一行写一条语句，表达式中的空格和换行都可以调整。语句不使用分号。

### 语句

| 用途 | 写法 | 说明 |
| --- | --- | --- |
| 赋值 | `let <变量> <表达式>` | 变量首次赋值时自动创建。 |
| 内存赋值 | `let @ <地址表达式> <值表达式>` | 将值写入指定内存地址。 |
| 整数输入 | `read <变量>` | 从标准输入读取一个整数。 |
| 字符输入 | `get <变量>` | 读取下一个非空白字符，并保存其字符编码。 |
| 整数输出 | `write <表达式>` | 输出表达式的整数结果，不自动换行。 |
| 字符输出 | `put <表达式>` | 将结果转换为字符输出，不自动换行。常用 `put 10` 输出换行。 |
| 条件分支 | `if <条件> ... end` | 条件结果非零时执行分支。可选 `else` 分支见下方示例。 |
| 循环 | `while <条件> ... end` | 条件结果非零时重复执行循环体。 |

`if` / `else` 示例：

```text
read score
if > score 59
  put 89
else
  put 78
end
put 10
```

条件成立时输出字符编码 `89`（`Y`），否则输出 `78`（`N`）。`if` 的 then/else 分支共用一个 `end`，嵌套语句块各自需要一个 `end`。`while` 循环也用 `end` 结束。程序末尾允许保留一个顶层 `end`，与仓库中的示例保持一致。

### 表达式

前缀表达式将运算符写在操作数前；二元运算符后按顺序写两个操作数。表达式可以嵌套：

```text
let total + price tax
let result * + a b 2
```

中缀表达式必须放在括号中，括号也可用于改变优先级：

```text
let total (price + tax)
let result ((a + b) * 2)
```

支持的运算符及中缀优先级（从高到低）：

| 运算符 | 含义 |
| --- | --- |
| `*` `/` `%` | 乘、除、取模 |
| `+` `-` | 加、减 |
| `==` `!=` `<` `>` `<=` `>=` | 相等、不等及大小比较 |
| `&` | 按位与 |
| `|` | 按位或 |

比较表达式的结果为 `0` 或 `1`；`if` 和 `while` 将 `0` 视为假，非零值视为真。`&` 与 `|` 是整数按位运算。整数加、减、乘按 32 位二进制补码回绕；最小负数除以 `-1` 时结果回绕为最小负数、余数为 `0`。除数或模数为 `0` 时会产生运行时错误。

### 内存寻址

`@` 后跟一个地址表达式，用于读取或写入该地址。可用地址为 `1` 到 `262144`：

```text
let @ 123 42
write @ 123
put 10
```

这段程序将 `42` 写入地址 `123`，再输出该值和换行。不要使用范围以外的地址。

## 示例程序

以下程序从输入读取一个整数，并输出它的阶乘：

```text
read n
let result 1
while > n 0
  let result * result n
  let n - n 1
end
write result
put 10
end
```

将代码保存为 `MoProgram/factorial.mo`，即可从菜单选择运行。`examples/` 中也有阶乘、最大值、闰年判断、Collatz 序列和大小写转换等示例；运行菜单读取的是 `MoProgram/` 目录。

## 当前语法限制

- 标识符由英文字母组成，大小写敏感；数字字面量为非负十进制整数。
- 数值范围为有符号 32 位整数；过大的数字字面量会产生解析错误。
- 二元运算符都需要两个操作数；不支持一元负号。需要表达负数时，可写成 `0 - n`。
- 中缀表达式必须使用括号括起；普通的前缀表达式不需要括号。
- 当前词法分析器不支持源代码注释或字符串字面量，请勿在 `.mo` 文件中添加 `//` 注释。
- `put` / `get` 面向字符，`write` / `read` 面向整数；输入输出指令都不会自动添加换行。
- 循环带有执行保护：单个循环超过 100,000,000 次迭代或运行超过 10 秒会报错。

解析错误和运行时错误会显示在命令行中。Makefile 当前提供编译和清理目标，没有单独的自动化测试目标。
